# Architecture

The edit manifest is the source of truth for video. Parsing and validation convert it into immutable `Project`, `Shot`, and `Grade` values. The timeline module calculates playback durations and overlap offsets without depending on FFmpeg. The filter-graph builder turns the project into filter syntax, while `FFmpegRenderer` handles input validation, command assembly, process execution, and atomic delivery. `probe` provides a read-only adapter for FFprobe; `credits` writes the soundtrack attribution alongside the render.

The image path is independent of the video manifest. `image_processing` accepts painted grayscale masks from an image editor or optional MaskFormer ADE20K masks. It applies different detail-sharpening strengths by region, gates sharpening by local texture, fades mask effects inward from boundaries, clips high-pass detail to limit ringing, and can lift selected highlights through a separate mask. A color-overlay preview makes selections visible. OpenCV, Pillow, and NumPy are optional image dependencies; ONNX Runtime is only needed for automatic masks. Photo adjustments preserve dimensions and do not synthesize scene content.

Video editing decisions (clip in-points, speed, grade, transitions, location slates, and portrait layout) remain separate from rendering mechanics. A future NLE or alternate encoder can consume the same project data without changing the project format. FFmpeg calls use argument arrays rather than shell command strings, and rendered files are promoted into place only after a successful encode.
